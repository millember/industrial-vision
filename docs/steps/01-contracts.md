# Шаг 1 — требования и границы интеграции

## Объём

Серверный шаг 1 из [плана Нияза](../../INDUSTRIAL_VISION_BACKEND_NIYAZ.md): подготовить конкретные требования, HTTP-контракт и формат адаптера модели. Команда сможет работать с одинаковыми JSON до подключения реальной модели.

Шаг не добавляет БД, авторизацию и анализ в код приложения. Существующий FastAPI-каркас до этой работы уже находился в незакоммиченном состоянии; его изменения не входят в коммит документов.

## Наблюдаемые критерии шага

| Критерий | Состояние |
|---|---|
| Зона Нияза отделена от Android и модели | Описана в требованиях |
| Вход снимка, результат, ошибки, повторы и «Сообщить» зафиксированы | Описаны в API-контракте |
| Координаты привязаны к сохраняемому снимку | Описаны размеры, нормализация и photo_id |
| Три состояния и недостаток данных различимы | Четыре JSON-примера |
| Сбой модели не превращается в успешную оценку | Контракт ошибок 502/503/504 |
| Классы модели и условия отсутствия крепежа заданы | Описаны в контракте адаптера |
| Markdown-ссылки и JSON проверены | 14 файлов, 24 ссылки, 14 JSON-файлов/блоков; статусы, цвета, рамки и пример адаптера согласованы; git diff --check без ошибок |
| Контракт принят Константином и Софией | Ожидает их подтверждения; сообщения участникам не отправлялись |
| Доступен релиз на домашнем сервере | Выполняется отдельно после коммита; SSH-доступ проверяется фактически |

Техническая подготовка документов не означает принятие контракта участниками. Для перехода к шагу 2 достаточно рабочего проекта схем; решения о реальном интерфейсе модели остаются открытыми до ответа Софии.

## Публикация шага

На этом шаге публикуется версия документов, без запуска приложения и изменения маршрутов Traefik. Целевой каталог: `~/services/industrial-vision/releases/<полный-хеш-коммита>/`. Релиз содержит только явный список документов этого коммита.

После восстановления SSH передать архив, сверить SHA-256 каждого файла и атомарно обновить указатель `current-docs`. Старые релизы сохраняются. Для отката переключить указатель на предыдущий проверенный релиз. Использовать общую блокировку `~/services/.home-server-deploy-lock`, не снимать чужую блокировку.

Запуск действующего FastAPI, постоянные данные и HTTPS — самостоятельная операция при реализации серверных шагов. Копия документов на сервере не означает работающий API.
